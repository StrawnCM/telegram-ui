# Telegram UI

A custom Telegram client for macOS — exploring new UI patterns and interaction models beyond the official app.

## Status

v1 scaffold is live:

- Carousel-first contact navigation with keyboard support
- Center-stage chat panel with mock conversation data
- Message composer for local UI flow testing
- Auth/API stubs ready for TDLib integration in a later milestone

## Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```

Build artifacts are generated in `dist/`.
